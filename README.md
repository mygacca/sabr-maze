# متاهة الصبر

لعبة متاهة بالعربية: أمِل جوالك لتدحرج الخرزات إلى النجمة في المركز، وتجنّب الحفر.

**العب الآن:** https://mygacca.github.io/sabr-maze/

- تعمل على الجوال بمستشعر الإمالة (افتحها من رابط `https`).
- على الحاسوب: الأسهم أو السحب بالفأرة.
- 12 مرحلة، ويُحفظ تقدّمك وأفضل أوقاتك في المتصفح.

شرح بنية الشيفرة في [CLAUDE.md](CLAUDE.md).

## تثبيت التطبيق على الجوال
**أندرويد (Chrome):** افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق» (أو «إضافة إلى الشاشة الرئيسية»).

**آيفون (Safari):** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية» ← «إضافة».

بعد التثبيت يفتح بملء الشاشة ويعمل دون إنترنت. التعديلات الجديدة تظهر عند فتحه التالي وأنت متصل بالإنترنت.
